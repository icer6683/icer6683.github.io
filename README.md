# AI Research Website

This is a lightweight static personal research website inspired by the compact academic layout of Justin Curl's homepage.

## Customize

- Add a preferred email address or contact profile to the About section.
- Add PDF links to the two paper entries when they are available.
- The About section uses `assets/headshot.jpg` as a responsive circular portrait.
- The contact marks use locally stored SVGs from the MIT-licensed Bootstrap Icons set.
- Add future notes and essays to the Writing section alongside the thesis and newspaper columns.

Open `index.html` directly in a browser to view the site.
